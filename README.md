# 5 Functional Requirements Implemented so far:

1. User Login: Users will be able to login and update their profile information. Each user will have their own account so that their media lists, progress, groups, and other information can be connected specifically to them. This will also allow users to have their own experience on the application without their information getting mixed up with other users.

2. User Logout: Users are able to logout and delete their account. 

3. Media Search and Browsing: Users will be able to search for different types of media such as TV shows, movies, animated shows, and books. Users will be able to search by title, media type, genre, author, or series to find specific media they are interested in. Once a user finds media they will be able to add it to their personal media list or associate it with a group. 

4. Personal Media List: Users will be able to add or remove media from their own personal list so they can keep track of what they are currently watching or reading. Users may also be able to organize their media into categories or sort their list based on attributes such as title, genre, or media type. Each entry in the media list will be attributed to the user who added it.

5. Progress Tracking: Users will be able to update and retrieve their current progress for the media they are watching or reading. For example, a user watching a TV show can update what episode they are currently on, while someone reading a book can update their current chapter. This progress will be stored with the user’s media information and can be updated as they continue watching or reading. This is one of the main functions of SamePage because it allows both the user and their group members to know exactly how far they have gotten.
